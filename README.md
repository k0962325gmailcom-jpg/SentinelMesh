### 🚨 The Problem
- 70% of cyber attacks in India target students & small businesses
- Existing security tools are expensive, complex, and slow
- Phishing and malware cause crores in losses every year

### 💡 Our Solution - SentinelMesh
SentinelMesh is a next-gen cybersecurity mesh that detects malware, phishing links, and threats in real-time using AI. Built for Bharat, for a safer tomorrow.

**Key Features:**
- ⚡ Real-time file malware scanning (<2 sec)
- 🔗 AI-based phishing URL detection
- 📊 Interactive threat analytics dashboard
- 🔒 95% detection accuracy
- 🌐 Fast, lightweight, mobile-friendly

### 🛠️ Tech Stack
- Frontend: Next.js 14, TypeScript, Tailwind CSS
- Backend: Node.js, AI/ML Detection Engine
- Deployment: Vercel
- Security: Real-time threat intelligence

### 🌍 Impact - How We Build a Better Future
- Protects Digital India initiative by securing students & startups
- Free for students, affordable for small businesses
- Prevents data theft and financial fraud
- Aligns with UN SDG 9 - Industry, Innovation & Infrastructure
